# Как самой менять услуги, мастеров и предложения

Тексты на сайте «Вторник» в трёх блоках берутся из Google-таблицы. Остальное на странице так не меняется.

Пока таблица не подключена, сайт показывает запасной вариант — то, что уже свёрстано.

## 1. Создайте таблицу

1. Откройте [Google Таблицы](https://sheets.google.com) и создайте пустую таблицу.
2. Внизу должны быть вкладки. Назовите их точно так, включая буквы:
   - Услуги
   - Мастера
   - Предложения
   - Ф. Салона
   - Основная инфа

## 2. Загрузите готовые строки

В папке `sheets-seed` лежат три файла. Каждый файл — своя вкладка.

Для каждой вкладки:

1. Откройте нужную вкладку.
2. Меню **Файл → Импорт → Загрузка**.
3. Выберите файл:
   - вкладка «Услуги» — `uslugi.csv`
   - вкладка «Мастера» — `mastera.csv`
   - вкладка «Предложения» — `predlozheniya.csv`
4. В настройках импорта выберите **Заменить текущий лист**.
5. Разделитель — запятая. Нажмите «Импортировать данные».

Первая строка — названия колонок. Её нельзя удалять и переименовывать.

Колонка «показывать»: напишите `да`, если строка должна быть на сайте. `нет` или пустая ячейка — строка скрыта.

Если на вкладке «Предложения» не останется ни одной строки с `да`, этот блок на сайте пропадёт целиком.

Вкладка «Ф. Салона» — фото интерьера под заголовком про тихий праздник. Колонки: «порядок», «фото_ссылка», «показывать». На сайт попадают первые три строки с `да`, по порядку: левая карточка, средняя, маленькая справа. Пустая ссылка оставляет серую заглушку.

Вкладка «Основная инфа» меняет контакты. Колонки: «Дни Работы», «Время», «Адрес», «Почта», «Номер», «Соц Сети». Адрес, почту и номер достаточно написать один раз в любой строке. В «Соц Сети» — название и ссылка, например `Telegram https://t.me/vtornik`, каждая сеть с новой строки или в новой строке таблицы. Если в названии есть звёздочка, как в `Instagram*`, под списком появляется примечание про Meta. Нет звёздочки — примечания нет. В «Время» напротив дня пишите часы или `выходной`. Пустая ячейка оставляет на сайте прежний текст.

## 3. Вставьте программу, которая отдаёт таблицу сайту

1. В таблице: **Расширения → Apps Script**.
2. Удалите текст, который уже стоит в редакторе.
3. Откройте файл `apps-script/Code.gs` в проекте сайта и скопируйте его целиком в редактор.
4. Нажмите **Сохранить**.

## 4. Дайте сайту ссылку на таблицу

1. В Apps Script нажмите **Развернуть → Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: вы.
4. У кого есть доступ: **Все** (то есть любой, у кого есть ссылка).
5. Нажмите «Развернуть», разрешите доступ, если спросит.
6. Скопируйте адрес, который заканчивается на `/exec`.

Этот адрес нужно записать в файл `.env` рядом с сайтом, одной строкой:

```
GOOGLE_SHEETS_URL=вставленная-ссылка
```

Файл передайте разработчику. Сам адрес в интернет как «страницу сайта» выкладывать не нужно, но таблица должна открываться по нему.

После правок самой программы снова откройте **Развернуть → Управление развёртываниями**, карандаш, версия «Новая версия», и сохраните. Адрес останется тем же.

## 5. Как править содержание

- Новая строка в таблице — новая карточка на сайте.
- «показывать» = `нет` — карточка скрыта, строку удалять не обязательно.
- Порядок — число: 1 идёт раньше, чем 2.
- Цену пишите так, как она должна выглядеть на сайте, например `от 3 500 ₽`.

Фото мастера или предложения:

1. Загрузите снимок в Google Drive.
2. Правый клик по файлу → **Настроить доступ** (или «Открыть доступ»).
3. Выберите **Все, у кого есть ссылка**.
4. Скопируйте ссылку и вставьте её в колонку «фото_ссылка» — у мастеров или у предложений.

Если ячейка фото пустая, на сайте останется прежняя картинка-заглушка.

Изменения появляются на сайте в течение минуты.

## Если что-то не появилось

- Не удаляйте первую строку с названиями колонок.
- Не переименовывайте вкладки. Нужны именно «Услуги», «Мастера», «Предложения», «Ф. Салона» и «Основная инфа».
- Файл в Drive без доступа «все, у кого есть ссылка» на сайте не откроется.
- В «показывать» пишите слово `да`. Пустая ячейка строку скрывает.
- Если меняли программу, обновите развёртывание до новой версии.
